## Pertanyaan umum

**Apa itu Free Nodes Radar?**

Free Nodes Radar mengumpulkan server proxy gratis yang dibagikan secara publik (VLESS, VMess, Shadowsocks, SSR, Trojan, Hysteria2, dan TUIC), membuang duplikat dan server rusak, menguji masing-masing, memberi nama sesuai negara, lalu menerbitkan server yang berfungsi sebagai langganan siap pakai.

**Langganan mana yang harus saya pakai?**

Gunakan tautan Clash untuk Clash Verge Rev, Clash Party, FlClash, Clash Meta for Android, dan Stash; tautan V2Ray untuk v2rayN, v2rayNG, Shadowrocket, NekoBox, Hiddify, dan Karing; serta tautan sing-box untuk aplikasi resmi sing-box.

**Bagaimana cara menambahkan langganan?**

Salin tautannya, buka aplikasi, cari menu Subscriptions atau Profiles, tambahkan yang baru, tempel tautan, lalu perbarui. Aplikasi Clash, v2rayNG, dan sing-box juga mendukung impor sekali klik dari halaman ini.

**Seberapa sering daftar diperbarui?**

Setiap 6 jam, mulai pukul 22.17, 04.17, 10.17, dan 16.17 UTC (05.17, 11.17, 17.17, dan 23.17 WIB), masing-masing sekitar setengah jam. Atur aplikasi Anda agar memperbarui langganan otomatis setiap 6 jam.

**Mengapa beberapa server tidak bisa saya pakai?**

Server gratis sering mati, dan pengujian dilakukan dari pusat data di luar negeri, jadi server bisa berfungsi di sana tetapi diblokir di negara Anda. Gunakan grup pemilihan otomatis atau uji latensi di aplikasi untuk menemukan server yang cocok.

**Apakah aman memakai server gratis?**

Pengelola server bisa melihat ke mana lalu lintas Anda pergi. HTTPS tetap mengenkripsi isi halaman, tetapi jangan masuk ke rekening bank, email, atau akun sensitif lain melalui server gratis.
